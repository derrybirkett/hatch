## 🎨 What Hatch Generates

### Applications (5)
1. **Website** - Marketing landing page (Next.js)
2. **Dashboard** - Main SaaS app (React)
3. **Blog** - Content platform (Next.js)
4. **Docs** - Documentation site (Nextra)
5. **API** - Backend server (NestJS)

### Libraries (4)
1. **@hatch/ui** - shadcn/ui components
2. **@hatch/auth** - Authentication logic
3. **@hatch/billing** - Stripe integration
4. **@hatch/shared** - Utilities & types

### Infrastructure
- PostgreSQL database with Prisma
- Playwright E2E tests
- Docker configuration
- CI/CD workflows

## 🚀 Quick Start (Future Users)

```bash
# Install Hatch
npm install -g hatch-cli

# Generate project
hatch init my-saas --story "A project management tool for teams"

# Start development
cd my-saas
pnpm install
pnpm dev

# Apps running on:
# - Website:   http://localhost:3000
# - Dashboard: http://localhost:4200
# - API:       http://localhost:3333
# - Blog:      http://localhost:3002
# - Docs:      http://localhost:3001
```
